# 云阅卷平台界面操作与异常恢复

## 首页状态

阅卷页通常位于：

```text
https://cloud.swomr.com/web/main.jsp
```

页面顶部信息中通常包含：

```text
考试名称 | 科目 | 题号 | 单评 | 评阅量 | 平均分 | 保密号
```

题目图片可能是答题卡的局部扫描，单张图片中常包含多个题号，不能仅凭当前视图猜测题目。

## 单份试卷

推荐顺序：

1. 读取当前标题和“评阅量”。
2. 确认题号、满分和保密号。
3. 点击“整图”或“放大”，读取学生作答。
4. 判断每个得分点。
5. 点击对应数字分或“满分/零分”。
6. 等待提交完成，重新读取页面。

验证提交成功的证据：

- 评阅量加一；或
- 保密号变为下一份；或
- 页面显示暂无任务。

出现以下情况时不要再次点击：

- 提示“第 N 个得分点未填写分数”。
- 顶部评阅量没有变化但仍显示旧保密号。
- 当前元素编号失效或页面正在加载。
- Chrome 焦点短暂切换。

先关闭提示、重新读取状态，再决定是否重试。

## 题目定位

答题卡可能包含两页或多栏。第 5 题通常在左栏中下部，但这只是版式提示，不是可靠定位规则。

每次判断前必须看到：

- 题目编号；
- 三个答题位置；
- 学生手写内容。

如果截图中只看见其他题号，说明视图停留在别处；缩小、全图或重新加载后再继续。不得用错误的截图区域批量提交。

## 整图与高清图

- “整图”适合确认作答在答题卡中的位置。
- 放大后的单题区域适合 OCR。
- 如果页面资源可见 `showMaskImage.do` 地址，可在同一登录会话的新标签页打开以提高分辨率。
- 不要尝试未登录的直链；通常返回 404。

## 大量批阅

- 每次 20–30 份，避免单次执行超时。
- 每份都读取当前状态后才能点击。
- 保持题目号在 OCR 文本中作为安全校验，但题号本身可能被识别成近似符号；若题号缺失，退回人工确认。
- 每批结束后记录起始和结束评阅量。
- 不因速度快而跳过异常；错误提交会污染整组数据。

## 回评模式

回评列表按时间倒序显示。

- 点击具体时间行加载该试卷。
- 修改分数后可能自动保存并跳到相邻试卷。
- 不要在一次分数点击后继续点击“提交分数”；这很可能落到下一份。
- 如果必须批量修正，一次只选择一行、读取状态、提交一次分数，然后重新确认。
- 用户说“不需要批阅以前回评过的”时，退出回评模式并继续新的待评任务。

## 临时文件

连续截图可能占满临时目录并导致 `failedToCreateImageDestination`。定期删除本任务生成的无用截图，保留评分日志和脚本。不要删除来源不明的用户文件。
